# NOWA (No Waste)

 **Live Site:** [nowa-google-solution-challenge-2023.netlify.app](https://nowa-google-solution-challenge-2023.netlify.app/)

##  Overview

NOWA (No Waste) is a web-based platform developed as part of the Google Solution Challenge 2023. It aims to reduce global food waste and alleviate hunger by connecting food donors with those in need. According to the World Food Programme (WFP), 2.8 billion tons of food are wasted annually. NOWA offers a practical solution to redirect surplus food to vulnerable communities.

##  Purpose

The platform supports collaboration among:

- **Business Owners** (e.g., restaurants, bakeries)  
- **NGOs** (who identify communities in need)  
- **Individuals** (who are in need or can report deserving recipients)

Each user type is verified and authenticated before gaining access to platform features.

##  Features

- **Role-Based Access**  
  - **Business Owners & NGOs** can update the database with:
    - Organization name  
    - Location  
    - Food type and item  
    - Availability status  

  - **Individuals & Public Viewers** can browse the listings to locate available resources and validate legitimacy.

- **Live Data Table**  
  - Updates in real time to reflect current food availability.

- **Transparency & Accountability**  
  - Publicly accessible data to foster trust and ensure resources are used ethically.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Deployment:** Netlify  

##  Impact

NOWA enables efficient food redistribution, empowering local communities to combat hunger and reduce food waste through a transparent and collaborative approach.
